# Sahih Care is an AI-powered health misinformation checker.

Users can paste, forward, or upload a screenshot of a health claim, and SahihCare will:

🧠 Analyse the claim using Gemini <br>
🔎 Check it against reliable and relevant sources, including Malaysian government agencies and reputable Malaysian news <br>
🟢🔴🟠⚪ Give a simple verdict: 
Verified,
False,
Misleading,
Unverified <br>
💬 Explain the result in simple language <br>
🌐 Respond in the user's language <br>
🔗 Show supporting sources <br>

It is also accessible through Telegram bot @sahihcare_bot, simplifying the process of checking from the user side.
